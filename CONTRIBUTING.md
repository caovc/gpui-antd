# Contributing

This is an early alpha Rust-native Ant Design-inspired component library.
Please read [AGENTS.md](AGENTS.md), [architecture](docs/ARCHITECTURE.md),
[development and CI](docs/DEVELOPMENT.md), and the
[component playbook](docs/COMPONENT_PLAYBOOK.md) before contributing.

Contributions should be implemented in Rust/GPUI, with actual desktop and
WASM gallery previews. Do not submit HTML/React replacements for Rust
components. Keep public APIs documented, test behavior in the library,
and wait for both native and WASM CI before claiming release readiness.

Source and artwork licensing: project MIT; official Ant Design SVGs MIT
(see `crates/antd/assets/LICENSE-ANT-DESIGN-ICONS`);
GPUI Kit/GPUI Apache-2.0; IBM Plex Sans subset SIL OFL.
Do not remove attribution or add proprietary icon fonts.

Issue tracker: <https://github.com/caovc/gpui-antd/issues>.
